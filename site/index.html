Frequently Asked Questions

Do I need Wine or Steam installed on my host server? +
No. WineHQ (x86_64), Xvfb, and SteamCMD are entirely containerized inside the Docker image. You only need Docker Engine with Compose v2+ and Bun/Node on the host.
What are the system and CPU requirements? +
Windrose dedicated server binaries require a CPU with AVX / AVX2 instructions (Intel Haswell / AMD Zen or newer). Additionally, IPv6 must be enabled in the host kernel, and the container runs with network_mode: host to bind game ports and NAT traversal sockets.
How do players connect to my server? +
Windrose uses peer-to-peer NAT traversal with an 8-character hex Invite Code (e.g. 3f1f4cf6) generated on boot. Players enter this invite code in the game client to connect seamlessly without port forwarding. Direct IP/port connection is also supported.
Can I run multiple separate Windrose worlds on one machine? +
Yes. Kraken Hub was specifically engineered for fleet management. Each commissioned ship receives its own isolated directory, separate .env file, isolated save profiles, and auto-incremented port allocations (7777, 7787, 7797, etc.).
Is there built-in password or PIN authentication? +
Yes. Kraken Hub includes optional scrypt-hashed PIN authentication (4-12 digits) with per-IP rate limiting (5 failed attempts per 15 minutes) and signed session cookies.
