Deployment

Cast Off in 60 Seconds

Deploy via 1-line automated installers for Linux & Windows or run standalone with Docker.

🐧 Linux 1-Liner

Docker Engine

Automated Linux script. Checks CPU AVX, verifies Docker & Bun, compiles SvelteKit Hub, and sets up systemd service.

curl -fsSL https://thekraken.cloud/install.sh | bash

🪟 Windows 1-Liner

Native Win32

Zero-overhead native Windows engine. Runs on bare-metal with zero Wine or WSL2 virtualization.

irm https://thekraken.cloud/install.ps1 | iex

🛠️ Manual / Headless

Git + CLI

Clone the repository and run the SvelteKit Hub manually or start a standalone Docker container.

git clone https://github.com/C9RE/Kraken.git cd Kraken/hub && bun install && bun run build PORT=8783 bun run start
